# Classroom Suite

Classroom tools for daily use: a dashboard (clock and bell schedule), table points, a name spinner, and a topic picker. They all share one set of classes, tables, and rosters.

## Files

```
index.html        Dashboard: clock and bell schedule
tracker.html      Table points
spinner.html      Name spinner
topics.html       Topic picker
activities.html   Review game, station rotations, tally, partners and groups
noise.html        Noise meter
seating.html      Seating charts and room setup (tables, seats, layout)
planner.html      Weekly planner: courses, snow-day shift, printable week
today.html        Today screen: class boards, warm-up timer, Flag of the Week, lesson deck
present.html      Show published Google Slides with tools on top
help.html         Help and the menu tour
shared/guide.js   First-visit setup guide and tour
settings.html     Classes, tables, rosters, seat shuffle, bell schedule, countdowns, backups
sub.html          Printable substitute packet
shared/style.css  Shared look
shared/core.js    Shared data and helpers
```

## Publishing

In the repository, go to Settings → Pages, choose "Deploy from a branch," pick `main` and `/ (root)`, and save. The site appears at `https://<your-username>.github.io/<repo-name>/settings.html`.

## Student data

Student names and points are stored only in the browser you use, never in these files. Use **Download backup** on the settings page regularly and keep the file in your school Google Drive. **Restore from a backup** brings everything back on the same or a different computer.
