    Bell schedule

    Show

    The dashboard uses this to show the current period. A period whose name matches a class (like "Period 2") links to that class automatically.

    Countdowns

    Show

    Upcoming dates for the dashboard, like a unit test or the end of a school day. The dashboard shows the three closest. Add a time (like 3:45) to count down to that moment; without one, it counts days. Each one drops off once it passes.

    Words and tools

    Show

    What your groups are called, and which tools appear in the menu. Turning a tool off only hides it; nothing is deleted.

    Appearance

    Show

    Colors, fonts, and the name at the top of every page. These are saved in this browser only, so anyone else using the suite on their own computer can pick their own.

    Backup and data

    Show

    Everything is saved only in this browser on this computer. A backup is a file you keep yourself. Saving it to your school Google Drive lets you restore it on another computer.
